# pdfs

_pdfs_ is a PDF scripting language. It was born out of frustration with existing PDF tools for simple structural manipulations such as concatenating two PDFs, extracting specific pages, and inserting a blank page every other page[^1].

## Progress

I haven't gotten around to implement _pdfs_ yet. Some usage examples I hope to support can be found in the `examples` directory. I should note that _pdfs_ is statically typed.

[^1]: Yes, there is a need for that. The printers at my university only allow two-sided printing, which is awful when you are trying to print sheet music. The solution I came up with is to insert blank pages ever other page.
